# Coffee Tracker

**Coffee Tracker** is a HarmonyOS wearable sample application. The app allows user to track their caffeine usage.

# Technology Stack
**Languages**: ArkTS, ArkUI  
**Frameworks**: HarmonyOS SDK 5.1.0  
**Tools**: DevEco Studio 6.0.0  
**Libraries/Kits**:
- @ohos.router
- @ohos.data.preferences
- @ohos.events.emitter
